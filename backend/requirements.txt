# --- ASR -------------------------------------------------------------------
# Parakeet via ONNX Runtime. No PyTorch, no NeMo, no CUDA toolkit: that stack
# bundles to 3-4 GB and was the scaffold's highest-risk item. See
# docs/ARCHITECTURE.md section 2.
onnx-asr>=0.11.0

# Execution providers. onnxruntime is the CPU/CoreML build and works
# everywhere. For an NVIDIA GPU on Windows/Linux install onnxruntime-gpu
# INSTEAD (they conflict). CUDA does not exist on macOS.
onnxruntime>=1.20.0
# onnxruntime-gpu>=1.20.0   ; Windows/Linux + NVIDIA only

# NO VAD PACKAGE HERE, DELIBERATELY.
#
# The obvious choice, `silero-vad`, hard-depends on torch>=1.12 AND
# torchaudio>=0.12 -- not as optional extras, in its base requirements. Adding
# it drags all of PyTorch into the PyInstaller bundle and takes the installer
# from ~400 MB to 3-4 GB, which is precisely the outcome the ONNX architecture
# was chosen to avoid (docs/ARCHITECTURE.md section 2).
#
# app/vad.py imports silero lazily and degrades to an energy gate, then to
# whole-file chunking, so it stays useful without the package. To get proper
# VAD back, run Silero's ONNX model through onnxruntime directly (no pip
# package), or use onnx-asr's built-in long-form VAD.
#
# tests/test_requirements.py enforces this.
